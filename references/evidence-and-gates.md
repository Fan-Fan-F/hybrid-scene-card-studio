# 证据与闸口总表

本文件汇总 SKILL.md 全部闸口、必交证据与检查脚本。SKILL.md 正文在各阶段内联了每条闸口的简版（查什么/证据/不过怎么办）；本表是执行时的对照清单，与正文冲突时以正文为准并回报修订。每过一道闸口，须在项目记录里留痕（格式见 §5）。

## §1 闸口总表

| 闸口 | 阶段 | 查什么 | 必交证据 | 不过怎么办 |
|---|---|---|---|---|
| G0 包完整性 | 开工前 | SKILL 与 references 引用的每个文件真实存在于包内 | `audit_skill_links.py` 输出零悬空 | 停工：补文件或删链/内联，不许脑补执行 |
| G0.5 图像定性 | 开工前 | 定性卡五项齐备（主体身份与性格/动作姿态/造型要素与可动部件/原画特效语义/场景与主光源）；规格卡每项标注推导依据 | 落盘定性卡 + 规格卡推导依据栏（无空白项） | 定性缺项退回补；无推导依据的规格条目删除，不许开工 |
| G1 规格卡 | 开工前 | 规格卡 7 项齐备且可验收（视角/必动+最小可辨幅度/应稳定/构图规格/特效范围与纯度/层序合同/环境运动规格），每项有推导依据（见 G0.5） | 落盘规格卡 + 版本号；必动清单与用户点名项 + 对象结构逐项对账记录 | 缺项补写或问清，不许"先做着看" |
| G2 抠图出口 | 第一段 | 保边/真 alpha/半透明对照；遮挡罩 = 主体∪辉光∪近身物件；残渣（远离实体的低 alpha 暗像素）计数；**内部 alpha 完整度内查**（轮廓内不透明占比/封闭孔洞，浅色区必查）；派生掩膜从已验收源派生且形态复查（环带仍是环带） | 残渣脚本输出 + 残渣标注图；清理后复跑计数归零（或低于规格阈值）；黑白底对照图；内部 alpha 区域统计 + 修复后复跑；派生掩膜覆盖率/带宽统计 | 按距离阈值清零残渣后复跑；内部缺损在素材层补实（RGB 回原图），严禁成片遮盖，修复后派生掩膜重派生；不许带残渣/缺损进合成 |
| G11 特效原画选材 | 第一段（素材入场） | 特效原画四查：无异形空洞/姿势描摹、无自带人物残片；对称性合规格；干净度（无暗斑/杂色混入）；亮度分布与目标底色匹配预判（洗色分档，底板过 G4 后复核一次） | 选材卡（候选逐项判定 + 入选/淘汰结论 + 洗色预判与复核留痕） | 换原画重过本闸口；不许硬贴后靠动画化/增益补救 |
| G3 深度真伪 | 第一段 | 深度图是真深度，非渐变掩膜冒充 | 剖面线图 + 数值分布统计 | 换真深度来源重出，不许沿用假深度 |
| G4 底板闸口 | 第一段出口（两段制的门） | 底板单图正常尺寸：无雾带/台阶缝/重影/彩虹纹/补丁边/漂浮碎片；构图与原画一致；生成填充洞外零改动；生成单体轮廓自然度（无直线切口/几何边，必要时局部放大） | 底板单图 + `plate_diff_check.py` 差分输出（非编辑区最大像素差 = 0）+ 接缝剖面图（拼凑法时）+ 单体轮廓放大查记录 + 验收留痕 | 回第一段修底板；合成不开工 |
| G5 静止空间 | 注册后 | 拼回母图与原图对照；特效归属层正确；层序合同一致；极限角四边覆盖；空间四件套（接触影归属/溢光接收面+遮挡依据/视差梯度/真深度置换） | 拼回母图对照图 + 正/负极限角静帧 + 四件套逐项结论 | 静态错误在本阶段修完再进动画 |
| G6 保护区断言 | 形变后 | 一切形变场（置换/warp/网格）在保护区（脸、骨盆/裆部等）内数值归零 | `displacement_guard.py` 输出保护区统计断言为 0（或低于阈值）+ 保护区掩膜叠加图 | 保护区压平/豁免后复跑断言；不许调小权重蒙混 |
| G7 权重自检 | 烘焙前 | 摆动/变形权重与掩膜坐标标对部位；布料类掩膜实心连通（无孔洞/岛屿）、位移场低频平滑、边缘羽化 | 权重叠加可视化图（热力叠原图）逐项对部位 + 掩膜连通性结论 + 布料运动双帧 | 坐标错位重标；掩膜打洞重做；无自检图/运动帧不许烘焙 |
| G8 特效出口 | 动画后 | 轮廓独立性（与宿主轮廓重合率低于规格上限）；范围与纯度达规格标定；无氛围雾环/光晕垫（与特效本体前置的界限按 SKILL §7 明文区分）；宿主跟随与生命周期完整；附着物与宿主同场（同一位移函数、自身演化中心钉附着点）；**层序与包围**：取舍与层序合同一致、包围逐区判定、前缘掩膜错位有声明；**瞬时元素**：口径六项实测（同屏/占比/寿命/最长间歇/禁区穿入 = 0/关键物件扫过 ≤ 上限），禁区靠构造性方法而非拒绝采样；**烘焙类**：表观速度双口径实测 + 衰减比、中点重影差分、接缝步 ≤ 相邻最大步；**混合上限**：洗色预判与成片差分实测对照 | 轮廓叠加自证图（双色、两帧互异）+ `contour_divergence.py` 重合率数值 + 图层清单（自证无雾环层）+ 正常尺寸全图 + 前缘层开/关对照帧（启用前缘时）+ 包围逐区结论 + 瞬时元素探针输出与亮起帧 ≥2（不同位置）/无事件帧 ≥1 + 烘焙实测数据条（双口径速度/衰减比/重影 MAD/接缝步）+ 混色差分统计 | 改轮廓生成方式；删雾环类图层；不许放大描边凑范围；包围不成立先定性（选材/层序）再改；瞬时口径不达回排布重做；洗色超预判按换混合方式判据处置，不许无限提增益 |
| G9 环境运动 | 动画后 | 完整形态入场（无切片带）；同层运动一致；幅度/周期达可辨下限；主光源演化在必动清单内（缓慢呼吸/微闪、幅度克制）；共场一致（同一物理场的关联元素——水面/倒影、光源/投射与溢光、主体/接触影——共用同一运动场与同一时间演化，不许独立运动） | 三件证据：规格量级 + 运行时实测位移对照 + 双时刻拼图帧，另加同相位共场对照帧（关联元素相对关系一致） | 调幅度/周期后重交三件证据；共场不一致回对应关联对同场重做；不许以"理论在动"结案 |
| G10 验收与交付 | 交付前 | 双轨看图（正常尺寸全图 + 局部放大，头部放大必交）；实际拖动 + 连续播放亲验；拖动态帧序/双相位帧/实测位移曲线；交付文件新名 + 大小/版本对账；证据包齐备；每轮复核从不同失败机制入手（不以重复运行同一项检查充数，与冷启动评审并列）；A/B 对照版单变量 + 等价断言（做了对照版时） | 见 §2 证据图清单全套 + 交付对账信息（文件名/大小/版本标识/所依据规格版本）+ 对照版等价断言输出（逆映射逐字节相等/逐项统计一致等） | 缺哪项补哪项；静帧通过不等于过关；多变量对照版作废重做 |

## §2 证据图清单（每版交付必备）

命名建议：`<项目>/qa/<证据名>_v<版号>.png|jpg`，与交付文件同版号。

| 证据图 | 内容要求 | 对应闸口 |
|---|---|---|
| 定性卡（文档） | 五项定性齐备；规格卡每项推导依据可回溯到定性卡条目 | G0.5 |
| 底板单图 | 背景底板单独成图，正常尺寸 | G4 |
| 差分图 | 生成填充前后差分，非编辑区应为零 | G4 |
| 接缝剖面图 | 拼凑补洞时：横向剖面曲线 + 台阶/色差标注（用拼凑法才交） | G4 |
| 残渣标注图 | 抠图残渣像素热力/标注（头部与发光部位周边重点） | G2 |
| 隔离帧 | 关全部特效/辉光/氛围层、只剩底板 + 主体的定格（报脏点时必交，先定性后修复） | G2 |
| 选材卡（文档） | 特效原画候选逐项判定（异形描摹/对称/干净度/底色匹配）+ 入选结论 + 洗色预判 | G11 |
| 前缘层开/关对照帧 | 同一时刻同视角，前缘层 ON/OFF 各一帧（启用前缘层时必交） | G8 |
| 瞬时元素帧组 | ≥2 个不同位置的亮起帧 + ≥1 个无事件帧 + 探针/审计输出 | G8 |
| 深度剖面图 | 沿人物纵轴深度数值曲线 + 分布统计 | G3 |
| 拼回母图对照图 | 无动作全层拼回，与原图并排或差分对照 | G5 |
| 极限角静帧 | 正极限、负极限各一帧，查四边覆盖与遮挡 | G5 |
| 保护区叠加图 | 保护区掩膜叠在形变场/原图上 | G6 |
| 权重叠加图 | 每组摆动/变形权重的热力叠原图 | G7 |
| 轮廓叠加自证图 | 特效轮廓（色 A）vs 宿主轮廓（色 B）叠加，两帧互异 | G8 |
| 双相位帧 | 每个必动对象大间隔两态，演化可辨 | G8/§7 |
| 双时刻帧 | 同视角相隔足够时长的两帧，环境位移可辨 | G9 |
| 同相位共场对照帧 | 同一动画时刻的两帧（或同相位变角前后帧），关联元素（水面/倒影、光源/投射与溢光、主体/接触影）相对关系保持一致 | G9 |
| 预览拼图（≥6 帧） | 正面双相位 + 双向拖动态 + 头部放大 + 轮廓叠加等 | G10 |

| 人物周围放大图 | 人物周边区域放大，查雾膜/灰污/溢光落点 | G8/G10 |
| 动态预览 | GIF 或等价多帧媒体，与成品动画范围一致 | G10 |

## §3 断言清单（数值断言，输出随证据包交付）

| 断言 | 工具 | 通过标准 |
|---|---|---|
| 包链接完整性 | `scripts/audit_skill_links.py` | 悬空链接数 = 0 |
| 抠图残渣归零 | `scripts/alpha_residue_check.py` | 残渣像素数 = 0（或 ≤ 规格卡阈值） |
| 主体内部 alpha 完整度 | 区域统计（可脚本化，无专用脚本时以统计输出入证据） | 轮廓内不透明占比 ≥ 规格阈值 且 封闭孔洞数 = 0 |
| 瞬时元素口径六项 | 运行时探针/审计 | 同屏 ≤ 上限、占比在目标区间、寿命在区间内、禁区穿入 = 0、关键物件扫过 ≤ 上限 |
| 对照版单变量等价 | 逆映射/逐项统计/MD5 对照（方法随对照内容定，须可复核） | 非变量部分逐字节相等或逐项统计一致 |
| 洞外零改动 | `scripts/plate_diff_check.py` | 非编辑区最大像素差 = 0 |
| 保护区形变归零 | `scripts/displacement_guard.py` | 保护区内形变量均值与最大值 = 0（或 ≤ 规格卡阈值） |
| 特效轮廓独立性 | `scripts/contour_divergence.py` | 特效轮廓与宿主轮廓重合率 ≤ 规格卡上限 |

## §4 检查脚本清单

脚本均位于包内 `scripts/` 下，统一以 `python scripts/<脚本名>.py ...` 调用；**参数细节以各脚本 `--help` 为准**，本表只记用途与产出。

| 脚本 | 用途 | 典型产出 | 对应闸口 |
|---|---|---|---|
| `audit_skill_links.py` | 扫描 SKILL.md 与 references 中的文件引用，报告悬空链接 | 悬空链接清单（空 = 通过） | G0 |
| `alpha_residue_check.py` | 检测抠图残渣：远离实体的低 alpha 暗像素统计与标注 | 残渣计数 + 标注图 | G2 |
| `plate_diff_check.py` | 两图差分：校验生成/补洞的非编辑区零改动 | 最大像素差 + 差分图 | G4 |
| `displacement_guard.py` | 校验形变场在保护区掩膜内的数值归零 | 保护区内均值/最大值统计 | G6 |
| `contour_divergence.py` | 计算特效轮廓与宿主轮廓的重合率并生成叠加图数据 | 重合率数值 | G8 |

## §5 验收留痕格式

每过一道闸口，在项目记录（如 `qa/gate-log.md`）追加一行：

```
| 闸口 | 结论（过/不过） | 证据文件 | 验收人 | 时间 | 所依据规格版本 | 备注（不过时的处置） |
```

规则：

- 留痕与证据文件同时产生，不许后补口头结论；
- 验收人须实际看过证据图本体（正常尺寸），不得只读执行者的文字结论；
- 同一闸口复验追加新行，不覆盖旧行，保留打回历史。
