# 规格卡模板与生成路线细则

规格卡是全项目**唯一数据源**（SKILL §2 / 闸口 G1）：工人任务书、生成提示词、验收清单一律引用规格卡版本号；口头变更不算数。但规格卡之前还有一步：**先定性、后定案**（SKILL §1.5 / 闸口 G0.5）——先填 §0 定性卡，再填 §1 规格卡，且规格卡每一项必须注明由定性卡哪条属性推导；生成类素材先填 §2 构图规格卡；任何变更走 §3 变更记录；生成的使用边界按 §4 细则执行；特效原画入场另过 §5 选材卡（闸口 G11）。

## §0 图像定性卡模板（先于规格卡填写，复制使用）

```
# 图像定性卡 · <项目名>
源图：<文件与尺寸>

| # | 定性项 | 本图结论 |
|---|---|---|
| D1 | 主体身份与性格 | <是谁、什么气质；动效应有的"劲"与克制程度> |
| D2 | 当前动作姿态 | <静态张力在哪、哪些部位本就在运动趋势中> |
| D3 | 造型要素与可动部件 | <按结构逐项列：人物为头/发/臂/手/衣物/带饰/下摆/腿脚，其他主体按其结构类推> |
| D4 | 原画自带特效的语义 | <逐个特效：贴面还是离体、来源、生命周期阶段> |
| D5 | 场景与主光源 | <空间结构、天气/介质、主光源位置与性质> |
```

规则：五项缺一不许填规格卡；规格卡每项的"推导依据"栏只能引用 D1–D5 的条目，引用不到的条目删除。定性只写本图事实，不写上一张图的经验。

## §2 构图规格卡（生成素材专用，云/天气为范式）

凡云、天气、背景等**生成类素材**，生成前先填此卡、后生成、按卡逐项对图验收（防案例 A15）。通用字段：

| 字段 | 填法 |
|---|---|
| 元素数量 | 写死个数（如"只 2 团"），不许"若干" |
| 位置 | 每团/每个元素的位置（如"左上""右中贴山脊上方"） |
| 大小关系 | 元素间相对大小与主次（如"左上更大、右中更小"） |
| 高低/层次关系 | 如"一高一低、高者更远、低者更近" |
| 形态规格 | 云型/天气类型写明（如"积层云：底部较平带云影、顶部团块起伏受光"） |
| 单体轮廓自然度 | 每个单体边缘须自然过渡，禁止非自然的直线切口/几何边（验收时必要时局部放大查，案例 A20） |
| 非对称要求 | 明示禁止左右镜像/均匀排布等（如"禁止成排云堤、禁止左右对称"） |
| 留白区 | 必须保持干净的区域（如"中央主体站位区保持干净蓝天"） |
| 构图锁定 | 与原画构图关系（如"地平线/山脊线与原画一致，不许改构图"） |
| 洞外约束 | 生成只进补全区，洞外像素零改动（过 G4 差分断言） |

验收方式：生成图与本卡逐行对照（含单体轮廓自然度一行），任一行不符即打回重生成，不许"差不多"放行。

## §3 变更记录格式

规格变更（视角、云规格、幅度、特效范围等）一律追加记录，不许覆盖原规格：

```
| 版本 | 日期 | 变更项 | 旧值 → 新值 | 提出方（用户原话摘要/执行侧） | 影响范围（需重做的闸口/素材） |
```

规则：

- 版本号递增；每版交付物注明所依据的规格版本（防案例 B8）；
- 变更影响已过闸口的，对应闸口按新规格复验并在 gate-log 追加留痕；
- 工人任务书只引用版本号 + 本记录，不另行转述规格，防止转述漂移。

## §4 生成路线分工细则

1. **生成只进补全区**：生成内容只许进入被遮挡区域与需补全区域；主体本体与洞外区域一律不动，洞外零改动用 `scripts/plate_diff_check.py` 断言（非编辑区最大像素差 = 0）。
2. **主体默认真抠图**：生成"提取"主体是重画，不是抠图——线条会简化、给不出真 alpha、细节会漂移。主体的置换深度、摆动权重、特效轮廓等全部标定都基于原版主体像素；换生成主体等于全部标定推倒重标，成本与风险必须先向用户讲清。
3. **补全侧优先生成**：大面积有机纹理（云/水/雾/火）的补洞优先生成填充，拼凑法（镜像/平铺/移植）已实证留下台阶缝与重影（案例 B6）；使用拼凑法必须过接缝专项查。
4. **放宽口径的登记**：用户明示放宽保真口径（如"人物大致一样就好"）时才许评估生成主体，且必须在规格卡变更记录中登记：放宽内容、用户原话、适用范围。**放宽仅对当次项目生效**，不构成通则，不得沿用到其他项目或写回技能默认值。
5. **构图先行**：一切生成素材先过 §2 构图规格卡再生成；生成提示词须逐项包含规格卡约束（数量/位置/大小关系/留白区），禁止无约束提示词。
