# 失败案例集（开工前自查）

来源：一张贝吉特超蓝插画（1024×1536）动态卡实战，历经 v1–v5 五版、用户逐版实际把玩验收。以下问题全部真实发生。格式统一为：**症状 → 根因 → 修法 → 预防条款**（条款指向 SKILL.md 的 §/闸口）。开工前逐条自查，命中同类风险先按预防条款布防再动手。

**通用性声明**：本案例集只沉淀**失败机制与检查方法**（如何验），不沉淀某张图的答案（应该长什么样）。案例中的具体元素、数值、规格都是那一张图的历史案情，禁止当作其他项目的默认项照抄——每张新图先过定性卡（SKILL §1.5），规格由本图属性推导。

## P0 技能包自身

### P0 包不完整、链接悬空
- **症状**：交付到手的技能包只有 SKILL.md 本体，正文引用的 references（20+ 篇）、scripts、assets 全部缺失，所有链接悬空。执行者只能凭正文散文干活，关卡没有代码入口、没有证据格式。
- **根因**：打包时未做链接完整性检查。
- **修法**：v2 重构——正文只引用包内真实存在的文件；无法重建的原工具深潜内容改为诚实指针或删去。
- **预防条款**：SKILL §0 / 闸口 G0（开工先跑 `scripts/audit_skill_links.py`，零悬空才许开工）。

## A 类：画面缺陷

### A1 火焰静止
- **症状**（v1）：线条状火舌不动，特效只有整片波动感。
- **根因**：运行时 shader 统一波动冒充内部演化，没有帧序。
- **修法**：28 帧离线烘焙帧序（行波 + 径向胀缩 + alpha 呼吸 + 核心提亮）。
- **预防条款**：SKILL §7「必动项自身演化」/ 闸口 G8——每个必动对象交大间隔双相位帧自证演化，整片波动不算演化。

### A2 气焰错层
- **症状**（v1）：蓝色气焰留在背景层、不跟随人物。
- **根因**：背景补洞的遮挡罩只盖人物本体，没盖辉光范围，特效被当成背景补掉了。
- **修法**：遮挡罩 = 主体 ∪ 辉光光环 ∪ 近身物件，整体重建背景。
- **预防条款**：SKILL §5 遮挡罩合同 / 闸口 G2；§6 拼回母图查特效归属层 / 闸口 G5。

### A3 云是切片带
- **症状**（v1）：云被做成上下直线截断的条带。
- **根因**：从原图切条当云层，未补全完整云团。
- **修法**：完整云团素材入场。
- **预防条款**：SKILL §7「完整形态入场」/ 闸口 G9——环境元素禁止切片带冒充。

### A4 必动漏项与幅度不足
- **症状**（v1）：头发不动、衣摆摆幅太小、整体气势不足。
- **根因**：必动清单凭感觉列、幅度没有下限标定。
- **修法**：头发独立必动层、衣摆幅度翻倍。
- **预防条款**：SKILL §2 规格卡第 2 项 / 闸口 G1——必动清单与用户点名项逐项对账，每项标定最小可辨幅度。

### A5 人物周围灰污/暗雾（抠图残渣）
- **症状**（v2 出现、v5 查实）：发光手与头发周围天空有灰污。
- **根因**：抠图残留——远离实体（均距 11.6px）的低 alpha 暗像素共 13,393 个，叠在亮背景上就是一圈暗雾。
- **修法**：距实体 >3.5px 的低 alpha 像素清零（共清理 31,895 px），断言残渣归零。
- **预防条款**：SKILL §5 残渣检测出口 / 闸口 G2——抠图出口必跑 `scripts/alpha_residue_check.py`，残渣计数入证据。

### A6 裆部在动（置换场顶动保护区）
- **症状**（v2 提出、v4 复现、v5 查实）：裤裆的裤子在摆动。
- **根因**：不是摆动权重（裆部权重本就是 0），是深度置换图在骨盆区数值大（|v−128| 均值 45.6、最大 106），拖动时骨盆被置换推移约 7.5px。
- **修法**：置换图加骨盆保护区压平，断言保护区内 |v−128| = 0。
- **预防条款**：SKILL §7 形变场保护区断言 / 闸口 G6（`scripts/displacement_guard.py`）；用户报"某处在动"先分诊是哪一层场在推，不许盲改权重。

### A7 特效小气显脏
- **症状**（v2）：气焰范围太小、颜色发脏。
- **根因**：特效范围与纯度用了默认量级，未标定。
- **修法**：气焰扩围 1.24× 至全高、饱和 ×1.22 提纯。
- **预防条款**：SKILL §2 规格卡第 5 项（特效范围与纯度是标定项）/ 闸口 G1、G8。

### A8 云层不一致 + 云型不对
- **症状**（v2）：有的云动有的不动；云丑、不是积层云。
- **根因**：同层云运动未统一；云型未在开工前定为美术规格。
- **修法**：同层云统一运动；云型按用户规格（积层云）重做。
- **预防条款**：SKILL §7 同层一致性 / 闸口 G9；§2 构图规格卡 / 闸口 G1。

### A9 人物浮在场景外
- **症状**（v2）：人物像贴在卡片外、拖动时人景关系不明显、3D 化弱仍是 2D 感。
- **根因**：接触阴影没挂对层、没有溢光接收面、视差无梯度、没有真深度。
- **修法**：接触阴影钉场景层、溢光只落实体表面、视差系数梯度 0.20→1.22、Depth Anything 真深度 → WebGL 逐像素置换（脸部权重 0）。
- **预防条款**：SKILL §6 空间关系四件套 / 闸口 G5。

### A10 人物周围雾膜
- **症状**（v3）：人物周围一层雾蒙蒙。
- **根因**：代码层加了 aura_ring 径向雾环"营造氛围"，实为无接收面的雾垫。
- **修法**：删除雾环并以图层清单断言不存在。
- **预防条款**：SKILL §7 氛围禁令 / 闸口 G8——禁人物周围雾环/光晕垫，氛围只走有接收面的形式（光斑投影、前景粒子、实体表面溢光）。

### A11 背景层序错乱
- **症状**（v3）：整个背景乱、层互相遮挡。亲查底板：横向雾带、天上飘山体碎片、底部大片涂抹 + 矩形补丁边。
- **根因**：背景被多层"重造"、无层序合同、且没人单独看过背景底板就合成了。
- **修法**：v4 起两段制——背景回归原图只补洞、远→近层序锁死、底板单图先过闸才许合成。
- **预防条款**：SKILL §3 两段制 + §2 层序合同 / 闸口 G4、G1。

### A12 云不动了
- **症状**（v4）：云被当静态精灵处理 / 整层漂移慢到看不见（±7px、120s 周期）。
- **根因**：环境运动幅度/周期低于肉眼可辨下限，且无实测证据。
- **修法**：远带整层漂移 30px/40s，运行时实测位移与理论值一致。
- **预防条款**：SKILL §7 环境运动可辨下限（三件证据）/ 闸口 G9。

### A13 火焰轮廓 = 人物剪影
- **症状**（v4）：火焰轮廓跟人物一模一样，像描边。
- **根因**：火焰由人物 alpha 膨胀生成，天生描边。
- **修法**：角向谐波径向拉伸 + 13 条独立火舌（长 95–245px、异频涨落），火焰轮廓与人物轮廓叠加图自证大面积不重合。
- **预防条款**：SKILL §7 特效轮廓独立性 / 闸口 G8（`scripts/contour_divergence.py` 测重合率 + 叠加自证图必交）。

### A14 头发旁模糊
- **症状**（v4）：头发旁边有模糊的东西。
- **根因**：与 A5 同源（抠图残渣）叠加火焰帧软边压到头部。
- **修法**：残渣清理 + 火焰在头部实体内压暗（×0.18）。
- **预防条款**：SKILL §5 残渣出口 / 闸口 G2；§8 头部放大图必交 / 闸口 G10。

### A15 云构图跑偏
- **症状**（v5 两连）：第一次生成满天成排"云堤"；用户规格是"只两团大积层云、一高一低有层次、非对称、中央留干净蓝天"。
- **根因**：生成前没有把用户口语规格写成可验收的构图规格卡（数量/位置/大小关系/留白区），提示词无约束。
- **修法**：按规格卡重生成并逐项对图验收。
- **预防条款**：SKILL §2 构图规格卡 / 闸口 G1——一切生成类素材：先规格卡、后生成、按卡验收（模板见 spec-and-generation.md）。

## A 续：v5 复验新增

### A16 飘带一动就"碎"
- **症状**（v5 复验）：飘带静态看没问题，一运动像碎了一样。
- **根因**（推断）：飘带掩膜用多边形 + 颜色门抠出，内部可能有孔洞/岛屿，邻域位移不一致撕裂；或位移场含高频成分。
- **修法**：布料掩膜改实心连通域；位移场低频平滑（行波沿长度传播、根部衰减）；边缘羽化。
- **预防条款**：SKILL §7 布料类 warp 出口检查 / 闸口 G7——掩膜实心连通（禁颜色门打洞）+ 位移场低频 + 运动双帧验收。

### A17 必动清单漏手臂
- **症状**（v5 复验）：手臂完全不动，用户点名手臂要有轻微缓慢摆动——v1 至 v5 必动清单始终漏了手臂。
- **根因**：必动清单只对"用户最初点名项"对账，没按对象结构自查。
- **预防条款**：SKILL §2 必动清单 + §1.5 定性卡 D3 / 闸口 G1、G0.5——清单须按人体/对象结构逐项自查（头/发/臂/衣/带/下摆逐项过），不只对点名项。

### A18 附着物未绑定宿主
- **症状**（v5 复验）：能量球有自己的脉动，但没跟着手运动（手臂加摆动后此绑定为硬性）。
- **根因**：附着物自走一套运动，未与宿主共用位移函数。
- **修法**：附着物与宿主同场运动：宿主的位移函数即附着物的位移函数，附着物只许在此之上叠加自身脉动且中心钉在附着点。
- **预防条款**：SKILL §7 特效出口「附着物同场运动」/ 闸口 G8。

### A19 主光源无演化
- **症状**（v5 复验）：右上角阳光/光晕全程静止。
- **根因**：原规则只写了"环境微光要有接收面"，没写光源本身要有生命周期，主光源未进必动清单。
- **修法/预防条款**：SKILL §7「主光源演化」/ 闸口 G9——场景主光源列入必动清单：缓慢强度呼吸/光线微闪，幅度克制不许像闪烁。

### A20 单团云边缘"一刀切"
- **症状**（v5 复验，附截图）：左下云团底部边缘是一条直线切口——构图规格过了，但单团轮廓自然度没验。
- **根因**：生成素材验收只有构图层面的逐项对照，缺单体轮廓这一项。
- **预防条款**：SKILL §5 底板闸口 + §2 构图规格卡 / 闸口 G4——生成素材验收加"单体轮廓自然度"（边缘不许出现非自然的直线切口/几何边），必要时局部放大查。

### 规格变更记录（v5 复验轮，用户亲口）
- **变更**：衣服与裤子改为"可有略微风吹摆动"（推翻 v5 裤子近冻结口径），摆动只许低频小幅、整片同相；云漂移略加速。**裆部/骨盆区冻结红线不变**（A6 的置换保护区继续生效）。
- **沉淀的机制**：摆动许可与形变保护区是两个独立维度——规格放行布料摆动，不豁免置换保护区断言，两者分别验收。
- **预防条款**：SKILL §7 闸口 G6「摆动许可与保护区是两个独立维度」；变更落盘走 SKILL §2 / 案例 B8。

## D 类：生图特效路线轮（fx 实验线）

### D1 特效原画未经选材入场
- **症状**：候选特效原画逐张带病入场后才被发现：有的围着一个与本图主体发型/姿势都对不上的异形空洞（描摹了另一个身形）、有的左右镜像模板感强、有的带暗斑与杂火星不干净、有的亮度分布与目标底色不匹配。
- **根因**：特效原画没有入场选材闸口，靠逐张试错筛图；原画的先天缺陷动画化救不回来。
- **预防条款**：SKILL §5 闸口 G11——入场四查（无异形描摹/对称性合规格/干净度/亮度分布与底色匹配预判），选材卡留痕，不合格换图。

### D2 静图烘焙表观流速衰减 + 中点重影
- **症状**：流场平流 + 交叉淡化烘焙的循环帧，实测表观流速（特征跟踪与全局光流双口径）只剩构造值的约 1/4–2/5；淡化中点两支纹理叠印有轻微重影；一版因时间频率非整数周期，循环接缝步出现约 1.9 倍尖峰。
- **根因**：交叉淡化保循环必然吃掉表观速度；构造参数达标被误当表观达标，且无人实测。
- **预防条款**：SKILL §7「静图动画化上限与实测」/ 闸口 G8——双口径实测 + 衰减比入数据条、中点重影差分专项查、接缝步 ≤ 相邻最大步、整数周期锁定。

### D3 瞬时元素无口径 + 禁区拒绝采样的结构性失效
- **症状**：断续闪烁元素第一版凭手感排布被用户以"太不明显"否决，事后才补口径；另查实某生成区起点盒大半落进禁区圆盘，随机重掷永远过不了禁区检查、必走无检回退——禁区形同虚设。
- **根因**：口径后于实现；概率拒绝采样在"生成区与禁区大面积重叠"时不是偶发失效，而是必然绕过。
- **预防条款**：SKILL §2 第 8 项（口径先冻结）+ §7「瞬时元素口径与实测」/ 闸口 G8——六项探针实测回报；禁区用构造性方法（脱困 + 逐事件复查）+ 审计断言。

### D4 包围感不足与前缘层掩膜错位
- **症状**：特效只垫主体身后时包围感不成立；加前缘层后成立，但前缘掩膜取自静态未置换轮廓，与动画后实际轮廓有像素级错位，靠环带宽度吸收。
- **根因**：层序取舍未在合同中先定；掩膜与轮廓的时间基准不一致且错位量未申报。
- **预防条款**：SKILL §7「特效层序取舍与包围验收」/ 闸口 G8——取舍先入层序合同、包围逐区判定、前缘开/关对照帧必交、错位量与吸收关系入数据条。

### D5 主体内部 alpha 缺损成脏点（A5 的镜像问题）
- **症状**：主体浅色部位出现异色斑点。隔离帧（关全部特效层）下斑点仍在——脏在素材：主体轮廓内 alpha 大面积半透明且有封闭孔洞，身后亮色经孔洞不均匀透出；由碎片化轮廓派生的边缘带掩膜在该区退化成整片覆盖，又叠一层染色。
- **根因**：抠图出口只查轮廓**外**残渣（A5），没查轮廓**内**完整度；派生掩膜从未验收的碎片化源派生且未复查形态。
- **修法（机制）**：素材层补实 alpha + RGB 回原图；派生掩膜由修复后主体重派生并复查形态；修复区外逐像素一致断言。
- **预防条款**：SKILL §5 闸口 G2 内查 + 隔离帧分诊 + 派生掩膜规则——内外方向明文（外清零/内补实）；报脏点先隔离定性后动手。

### D6 加色混合亮底洗色被误当增益问题
- **症状**：特效叠在明亮底色上系统性变"薄"，外围辉光被冲淡偏白，色相只在核心与暗底段落保得住（成片差分像素实测可证）；过程中一度以"再提增益"当解法。
- **根因**：底色已饱和的通道加不进去，是加色类混合的物理上限；增益同涨核心与辉光，治不了通道饱和。
- **预防条款**：SKILL §7「混合模式物理上限」/ 闸口 G11、G8——按底色亮度预判并申报、成片差分实测混色、明文禁伪解法、给出换混合方式的判据；与 §2 纯度（合成前本体处理）分开验收。

### D7 对照版多变量齐改不可比
- **症状/定版**：同规格换色对照若排布/密度/种子随色一起变，结论不可归因。定版做法：只改一个变量，其余不变以"逆映射后逐字节相等"断言证明（模板与成品双断言）。
- **预防条款**：SKILL §8 单变量对照纪律 / 闸口 G10——单变量 + 可复核等价断言入证据，多变量对照作废。

## B 类：流程与验收失误

### B1 自判通过被推翻
- **症状**：多版在缩小拼图上看着没问题、正常尺寸缺陷可见（雾带、灰斑、接缝）。
- **根因**：验收只看缩略拼图。
- **预防条款**：SKILL §8 验收双轨 / 闸口 G10——正常尺寸全图 + 关键局部放大；清单打勾不许覆盖眼睛看到的瑕疵。

### B2 底板没单独验就合成
- **症状**（v3 教训）：只验拼图和人物放大，漏了背景单图这一关，底板缺陷带进合成。
- **预防条款**：SKILL §3/§5 两段制闸口 / 闸口 G4——底板单图亲验留痕（谁验、何时、结论）后才许合成。

### B3 同名文件交付被缓存顶住
- **症状**（v2）：用户打开还是旧版，一度误判"没改"。对账实证：两版 MD5/大小/内嵌帧数全不同，是用户端预览缓存。
- **预防条款**：SKILL §9 / 闸口 G10——每版必须新文件名交付（standalone-vN.html），交付时报大小与版本标识供对账。

### B4 权重坐标标错
- **症状**（v1）：腰带摆动权重标到胸口位置。
- **根因**：权重标定后没有可视化核对就烘焙。
- **预防条款**：SKILL §7 权重标定可视化自检 / 闸口 G7——烘焙前先出叠加可视化图对部位。

### B5 深度图造假未察
- **症状**：旧 depth.npy 实测只是底部渐变掩膜，不是真深度，险些沿用。
- **根因**：深度素材入场未做真伪抽查。
- **预防条款**：SKILL §5 深度真伪抽查 / 闸口 G3——剖面线/数值分布证明是真深度再用。

### B6 拼凑补洞在有机纹理上到天花板
- **症状**（v4 底板两轮）：镜像/平铺/移植补云，留下横向台阶缝、深色横线、山体发白重影、湖面彩虹纹。
- **根因**：补洞方法未按材质选，拼凑法不适用于大面积有机纹理。
- **预防条款**：SKILL §5 补洞按材质选法——有机纹理优先生成填充；拼凑法必须过接缝专项查（横向剖面查台阶、逐行色差）。

### B7 生成路线边界
- **症状/定版**（v4）：生成背景填充可用（锁构图、洞外像素零改动断言 MAD=0）；生成人物 = 重画不是抠图（线条简化、无真 alpha、细节漂移），与"人物像素不重绘"冲突。用户本卡放宽口径后仍决定人物用真抠图：置换深度、头发/飘带权重、火焰轮廓全部标定都基于原版人物像素，换人 = 全部重标。
- **预防条款**：SKILL §5 生成路线分工——生成只进被遮挡/需补全区域；主体默认真抠图；放宽口径必须由用户明示、只对当次项目生效、留档记录（细则见 spec-and-generation.md）。

### B8 规格变更漂移
- **症状**：视角 ±10°→±20°→±15°、云规格多轮变更，靠口头传递易漂移。
- **预防条款**：SKILL §2——规格表单一数据源：变更落盘、工人任务书引用同一规格表、每版交付注明所依据的规格版本（格式见 spec-and-generation.md）。

### B9 工人交付无证据风险
- **症状**：多轮出现脚本崩（exit 1）、个别结论先行于实物。
- **预防条款**：SKILL §9 工人交付协议——状态文件 + 证据文件（拼图/放大图/叠加图/断言输出）齐备才算交付；总指挥亲验关键证据，不转述未验结论。

### B10 静态验收代替动态验收
- **症状**（v1）：动效问题靠用户把玩才暴露。
- **预防条款**：SKILL §8 / 闸口 G10——交付前必须过"实际拖动交互 + 连续播放"维度：拖动态帧序、双相位帧、实测位移曲线；静帧拼图通过不等于过关。
