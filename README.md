# Hybrid Scene Card Studio（2.5D 动态卡牌 Skill）

把单张插画或已有分层素材，制作成可拖动、有内部景深与自然局部动画的动态收藏卡的 AI Skill（v3 实战修订版）。

- **原画保真优先**：以闸口（Gate）体系管住制作全程——开工前规格卡、阶段出口检查、必交证据图、配套检查脚本，规则不靠散文靠断言。
- **默认交付**：可启动、可拖动的动态网页 + 真实多帧预览，保留可编辑项目与独立素材。
- **参赛背景**：本包为「2026 华为开发者大赛 · 小红书 Skill 创新赛」参赛作品「2.5D 动态卡牌」的最终提交版本。

## 包结构

- `SKILL.md` — 技能正文（方法、闸口与执行顺序）
- `references/` — 证据与闸口总表、失败案例集、规格与生成细则
- `scripts/` — 五个检查脚本（链接完整性、alpha 残渣、轮廓发散、形变场保护、多帧差分）

## 使用

将本仓库作为 Skill 包导入任何支持 `SKILL.md` 规范的平台（如 WorkBuddy、码道 CodeArts 等）即可使用。开工第一件事是跑包完整性自检：

```bash
python scripts/audit_skill_links.py SKILL.md
```
